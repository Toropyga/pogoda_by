# Pogoda.by для Home Assistant — 0.1.4

[Русский](../README.md) | [English](README.en.md) | [Polski](README.pl.md) | [Беларуская](README.be.md) | [Deutsch](README.de.md)

Карыстальніцкая інтэграцыя для Home Assistant. Атрымлівае фактычнае надвор'е Белгідрамета праз RSS, а спіс краін і станцый — праз JSON API. Ключ API не патрэбны. Прагноз надвор'я не прадастаўляецца.

![License](https://img.shields.io/badge/license-MIT-brightgreen.svg)
![Version](https://img.shields.io/badge/version-v0.1.4-blue.svg)

> ⚠️ **Важная заўвага:** Інтэграцыя прадастаўляе поўную інфармацыю па метэастанцыям **у Беларусі**. Па станцыям у іншых краінах інфармацыя часта **недаступная або частковая**, бо сэрвіс Pogoda.by арыентаваны ў першую чаргу на даныя Белгідрамета (Беларусь). Калі вы выбралі станцыю з іншай краіны і сенсары паказваюць памылку ці становяцца недаступнымі, гэта звязана з недаступнасцю даных ад сэрвіса Pogoda.by.

## Усталяванне праз Marketplace / HACS

Інтэграцыя падтрымлівае ўсталяванне праз Marketplace / HACS з рэпазіторыя `Toropyga/pogoda_by`.

[![Усталяваць праз HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=Toropyga&repository=pogoda_by&category=Integration)

### Home Assistant 2026.11 і навейшы — Marketplace

Пачынаючы з **Home Assistant 2026.11**, HACS убудаваны ў Home Assistant пад назвай **Marketplace**. Асобна ўсталёўваць HACS не трэба. Marketplace даступны адміністратарам у наладах. Pogoda.by пакуль не ўваходзіць у агульны каталог, таму дадайце рэпазіторый па спасылцы.

1. Адкрыйце **Налады → Marketplace**.
2. Націсніце **Дадаць па спасылцы / Add from link**.
3. Увядзіце `https://github.com/Toropyga/pogoda_by` і націсніце **Дадаць / Add**.
4. Пры неабходнасці падключыце GitHub: ён патрэбны для карыстальніцкіх рэпазіторыяў. Калі тып не вызначыўся аўтаматычна, выберыце **Integration**.
5. Адкрыйце **Pogoda.by** і націсніце **Усталяваць / Install**.
6. Выберыце краіну і станцыю ў акне наладжвання. Калі Marketplace запатрабуе перазапуск, выканайце яго, затым перайдзіце да раздзела наладжвання ніжэй.

Першае ўсталяванне можа адразу адкрыць наладжванне без перазапуску. Пры абнаўленні ўжо ўсталяванай інтэграцыі кіруйцеся паведамленнем Marketplace пра неабходнасць перазапуску.

### Home Assistant 2026.10 і старэйшы — HACS

У ранейшых версіях патрэбны ўсталяваны і наладжаны [HACS](https://www.hacs.xyz/). Дадайце інтэграцыю як карыстальніцкі рэпазіторый:

1. Адкрыйце **HACS** у Home Assistant.
2. Націсніце **⋮ → Карыстальніцкія рэпазіторыі / Custom repositories**.
3. Устаўце адрас `https://github.com/Toropyga/pogoda_by`.
4. Выберыце тып **Інтэграцыя / Integration** і націсніце **Дадаць / Add**.
5. Знайдзіце **Pogoda.by**, адкрыйце яе і націсніце **Спампаваць / Download**.
6. Пацвердзіце спампоўванне прапанаванай версіі. Калі выпускі яшчэ не апублікаваны, HACS выкарыстоўвае асноўную галіну рэпазіторыя.
7. Перазапусціце Home Assistant і выканайце наладжванне, апісанае ніжэй.

Marketplace і HACS размяшчаюць файлы ў `/config/custom_components/pogoda_by/`, у тым ліку пераклады і папку `brand`. Надалей новыя апублікаваныя версіі можна спампоўваць праз адпаведны інтэрфейс.

Калі інтэграцыя ўжо ўсталявана ўручную, дадайце той жа рэпазіторый у Marketplace або HACS і ўсталюйце яе з заменай наяўных файлаў. Выдаляць запіс Pogoda.by ў раздзеле прылад і сэрвісаў для змены спосабу ўсталявання не трэба.

## Усталяванне ўручную

1. Скапіруйце папку `custom_components/pogoda_by` з гэтага праекта ў каталог канфігурацыі Home Assistant. Выніковы шлях павінен быць `/config/custom_components/pogoda_by/manifest.json`.
2. Перазапусціце Home Assistant.
3. Выканайце наладжванне, апісанае ніжэй.

## Наладжванне пасля ўсталявання

[![Дадаць інтэграцыю](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=pogoda_by)

1. Адкрыйце **Налады → Прылады і сэрвісы → Дадаць інтэграцыю → Pogoda.by**.
2. Выберыце краіну з даведніка, затым станцыю са спіса гэтай краіны. У подпісе станцыі пазначаны яе сапраўдны ID, а не пазіцыя ў даных JSON.
3. Дачакайцеся першага паспяховага атрымання RSS. Калі станцыя не публікуе падтрымліваныя даныя пра надвор'е, форма паведаміць пра гэта і дазволіць выбраць іншую станцыю.

Для некалькіх станцый дадайце інтэграцыю некалькі разоў. Паўторнае дадаванне той жа станцыі блакуецца. Каб змяніць станцыю, дадайце новы запіс і выдаліце стары, калі ён больш не патрэбны.

Гэта папярэдняя версія. Зыходны код: https://github.com/Toropyga/pogoda_by. Для ўсталявання ўручную спампуйце рэпазіторый праз **Code → Download ZIP** і распакуйце яго. У `custom_components` патрэбна толькі ўкладзеная папка `pogoda_by`. Для ўсталявання праз Marketplace / HACS асобны GitHub Release не абавязковы. Падрыхтоўка публікацыі апісана ў [HACS.md](../HACS.md) на рускай мове.

## Мовы інтэрфейсу

Падтрымліваюцца **беларуская (`be`), польская (`pl`), руская (`ru`), англійская (`en`) і нямецкая (`de`)** мовы. Перакладзены выбар краіны і станцыі, паведамленні пра памылкі, налады абнаўлення і назвы сенсараў.

Мова выбіраецца аўтаматычна паводле мовы інтэрфейсу Home Assistant у профілі карыстальніка. Асобны пераключальнік у інтэграцыі не патрэбны. Назвы сутнасцей, зададзеныя карыстальнікам, не перазапісваюцца.

Назвы станцый і тэкставыя значэнні, атрыманыя ад Pogoda.by, захоўваюцца ў зыходным выглядзе. Напрыклад, апісанні надвор'я, тэндэнцыя ціску і напрамак ветру з рускамоўнага RSS не перакладаюцца аўтаматычна; лікавыя паказанні аднолькавыя для ўсіх моў.

## Значок інтэграцыі

У інтэграцыю ўключаны значок **Pogoda.by** з празрыстым фонам:

- `custom_components/pogoda_by/brand/icon.png` — 256×256 пікселяў;
- `custom_components/pogoda_by/brand/icon@2x.png` — 512×512 пікселяў.

Home Assistant **2026.3 і навейшы** аўтаматычна выкарыстоўвае выявы з папкі `brand`. Дадатковыя налады ў `manifest.json` не патрэбны. Пры абнаўленні ўсталяванай інтэграцыі скапіруйце ўсю папку `pogoda_by`, перазапусціце Home Assistant і абнавіце старонку браўзера. Версіі Home Assistant да 2026.3 не падтрымліваюць лакальныя выявы інтэграцый гэтым спосабам.

Зыходная выява захавана ў `assets/pogoda-by-source.png`. Паўторна падрыхтаваць патрэбныя памеры можна ў Windows камандай `./tools/build_brand.ps1` з папкі праекта.

## Сенсары

Сенсар ствараецца, калі адпаведнае поле ўпершыню з'яўляецца ў RSS. Калі поле з'явіцца пазней, перазапуск не патрэбны. Калі раней даступнае поле знікне, сенсар стане недаступным; адсутныя паказанні не замяняюцца нулямі.

| Поле | Адзінка / тып | Дадатковыя звесткі |
| --- | --- | --- |
| Тэмпература | °C | Падтрымліваюцца адмоўныя значэнні, дзесятковая кропка і коска |
| Атмасферны ціск | hPa | Атрыбут `status`: тэндэнцыя з RSS |
| Тэндэнцыя ціску | Тэкст | Напрыклад, «падае» |
| Хуткасць ветру | m/s | `direction` і `speed_kmh`; адзінкі можна змяніць у Home Assistant |
| Напрамак ветру | Тэкст | Штыль не падмяняецца паўночным напрамкам ветру |
| Надвор'е | Тэкст | Поўнае апісанне і зыходны радок у атрыбутах |
| Час назірання | Часавая пазнака | `pubDate`, пераведзены ў UTC; інтэрфейс паказвае мясцовы час |
| Метэастанцыя | Дыягнастычны тэкст | ID, краіна, назва, каардынаты, гадзінны пояс, ICAO і спасылка |
| Вільготнасць | % | Толькі калі RSS яўна змяшчае гэтае поле |
| Парывы ветру | m/s | Толькі калі RSS яўна змяшчае гэтае поле |
| Бачнасць | km | Толькі калі RSS яўна змяшчае гэтае поле ў кіламетрах |

Вільготнасць, парывы ветру і бачнасць прадугледжаны парсерам як неабавязковыя палі, але іх наяўнасць у бягучым сэрвісе не пацверджана. Інтэграцыя не вылічвае іх з іншых даных.

Кожная станцыя прадстаўлена асобнай прыладай. Сутнасці маюць стабільныя unique_id, заснаваныя на краіне, ID станцыі і тыпе паказчыка. Імёны entity_id прызначае Home Assistant.

Інтэрвал паводле змаўчання — **1 гадзіна (60 хвілін)**. Кнопка **Наладзіць** у запісе інтэграцыі дазваляе выбраць ад 5 да 180 хвілін. За адзін цыкл выконваецца адзін RSS-запыт для ўсіх сенсараў станцыі. Даведнік загружаецца падчас наладжвання; звесткі пра выбраную станцыю захоўваюцца ў запісе і не патрабуюць паўторнага спампоўвання пры запуску Home Assistant.

Пасля абнаўлення значэнне паводле змаўчання прымяняецца да запісаў без яўна захаванага інтэрвалу. Калі інтэрвал ужо захаваны праз **Наладзіць**, ён захоўваецца; для абнаўлення кожную гадзіну задайце **60** уручную.

Пры памылцы HTTP, перавышэнні часу чакання або некарэктным RSS сенсары надвор'я становяцца недаступнымі. Home Assistant паўтарае абнаўленне аўтаматычна. Дыягнастычны сенсар станцыі захоўвае метаданыя лакальна і застаецца даступным. Паспяховы адказ са старой датай назірання не лічыцца сеткавай памылкай: правярайце час назірання. Інтэграцыя не гарантуе, што сама станцыя публікуе новыя вымярэнні кожную гадзіну.

Сутнасць `weather` з прагнозам не ствараецца; для паказу выкарыстоўвайце карткі сутнасцей, пліткі і графікі сенсараў. Лікавыя паказчыкі маюць device_class, state_class і стандартныя адзінкі Home Assistant.

## Праверка

Аўтаномныя тэсты разбору JSON/RSS выкарыстоўваюць стандартную бібліятэку Python:

```powershell
python -m unittest discover -s tests -v
```

Праверка бягучых адказаў сайта без усталявання Home Assistant:

```powershell
python tools/check_live.py --country BY --station 26851
python tools/check_live.py --country PL --station 12372
```

Скрыпт толькі чытае адкрытыя даныя. Ён не змяняе канфігурацыю Home Assistant. Для дыягностыкі паведамленняў інтэграцыі можна часова ўключыць:

```yaml
logger:
  logs:
    custom_components.pogoda_by: debug
```

## Стан праверкі гэтай зборкі

Праверка сінтаксісу, узгодненасці перакладаў і аўтаномныя тэсты выконваюцца лакальна; вынікі запісаны ў `VALIDATION.md` на рускай мове. У асяроддзі распрацоўкі няма тэставага Home Assistant. Прамы доступ да API/RSS у гэтым асяроддзі не працуе, таму фактычныя адказы сайта і поўны працэс усталявання ў працоўны Home Assistant яшчэ патрабуюць праверкі. Парсер даведніка падтрымлівае структуры «краіна → масіў станцый» і «краіна → аб'ект станцый». Змены схемы API, якія не падтрымліваюцца, прыводзяць да паведамлення пра памылку, а не да стварэння выдуманых даных.

Выкарыстоўваюцца стандартныя API ConfigFlow, OptionsFlow, DataUpdateCoordinator і SensorEntity. Мэтавая мінімальная версія — Home Assistant 2025.1; фактычная сумяшчальнасць яшчэ не пацверджана запускам у Home Assistant.
