# Проверка версии 0.1.1

Дата: 12 ноября 2026 года.

Интервал по умолчанию увеличен с 10 до 60 минут. Явно сохранённые пользовательские интервалы сохраняются.

Добавлена утверждённая иконка с надписью Pogoda.by. Созданы `brand/icon.png` (256×256) и `brand/icon@2x.png` (512×512); размеры, PNG-формат и прозрачность проверены. Скрипт `tools/build_brand.ps1` выполнен успешно. Подключение использует стандартную локальную папку `brand`, поддерживаемую Home Assistant с версии 2026.3. Отображение в работающем Home Assistant не проверялось.

Для Marketplace / HACS добавлен корневой `hacs.json`, подготовлены инструкции установки и публикации. Структура комплекта проверена перед упаковкой. Установка через работающий Marketplace / HACS и официальный сетевой валидатор HACS не запускались. Соответствие локальной структуры требованиям не является подтверждением завершённой установки.

Добавлена белорусская локализация `be.json`, уточнены польские формулировки настроек обновления. Генератор переводов и существующая проверка ключей расширены на четыре языка. Проверяются сообщения настройки, ошибки, параметры обновления и названия всех сенсоров. Текстовые данные самого RSS сохраняются на языке источника. Отображение переводов в работающем Home Assistant не проверялось.

Подготовлены полные переводы README на английский, польский и белорусский языки с навигацией между четырьмя версиями. Во всех версиях учтён встроенный Marketplace в Home Assistant 2026.11 и новее; прежний HACS описан отдельно для версий до 2026.11. Инструкции сверены с официальной документацией Marketplace. Проверяются полнота разделов, таблиц, совпадение команд и относительные ссылки. Эти изменения относятся к документации и не меняют версию исполняемого кода.

По запросу владельца весь подготовленный комплект выпускается как **0.1.1**, независимо от промежуточной локальной нумерации. Версия manifest и заголовки README согласованы с выпуском. Описание релиза на русском и английском сохранено в `RELEASE_NOTES.md`.

- **36 автономных тестов пройдены**, ошибок и пропусков нет (`python -m unittest discover -s tests -v`).
- 25 тестов проверяют разбор справочника, RSS и дат, включая пример из исходного package.
- 7 тестов проверяют HTTP-обработчик с подставным транспортом: сетевые ошибки, тайм-аут, ошибочный HTTP-статус, неверный JSON/кодировку, размер ответа, передачу ID станции. Они не проверяют реальное сетевое соединение и совместимость с установленным aiohttp.
- 4 проверки комплекта: синтаксис всех Python-файлов, manifest, соответствие ключей переводов и названий сенсоров.
- Проверка `compileall` завершена успешно.
- Ключи интерфейса на английском, русском, белорусском и польском языках согласованы.
- Проверка живого API скриптом `tools/check_live.py` не прошла: DNS-запрос завершился ошибкой `getaddrinfo failed`. Считать это подтверждением недоступности сайта для пользователя нельзя.
- Рабочий Home Assistant не изменялся. Установка, формы настройки, реальные обновления сенсоров, выгрузка интеграции и совместимость с конкретной версией Home Assistant пока не проверены запуском в Home Assistant.

Для завершения проверки в рабочем окружении: установить интеграцию вручную по README, выбрать страну и станцию, проверить первое и следующее обновления, изменение интервала и повторный запуск Home Assistant. Для быстрой проверки схемы данных без установки предусмотрен `tools/check_live.py`.
