# Подготовка Pogoda.by к установке через Marketplace / HACS

Версия 0.1.1 содержит файлы для установки через Marketplace / HACS. Установка в работающий Home Assistant ещё не проверена в среде разработки.

Начиная с Home Assistant 2026.11, HACS встроен как Marketplace: **Настройки → Marketplace**. Отдельная установка HACS на этих версиях не нужна. Для Home Assistant 2026.10 и старше остаётся прежний порядок установки HACS. Файл `hacs.json` и структура репозитория используются обоими вариантами.

## Что подготовлено

- В корне проекта находится `hacs.json`: название Pogoda.by, минимальная целевая версия Home Assistant 2025.1.0.
- Единственная интеграция размещена в `custom_components/pogoda_by/`; все необходимые при работе файлы находятся внутри этой папки.
- В `manifest.json` заданы `domain`, `name`, `version`, `documentation`, `issue_tracker` и `codeowners`.
- Иконки находятся в `custom_components/pogoda_by/brand/`. Их локальное отображение требует Home Assistant 2026.3 или новее; этот порог не ограничивает установку самой интеграции.
- README на русском, английском, польском и белорусском языках содержит инструкции для Marketplace, прежнего HACS и ручной установки.

`content_in_root` не задан: код находится в стандартной папке `custom_components`. `zip_release` не задан: HACS скачивает содержимое интеграции из GitHub. Полный ZIP проекта предназначен для ручной установки или передачи исходников; прикреплять его как HACS ZIP-артефакт не требуется.

## Публикация и обновления

1. Опубликовать весь проект в основной ветке публичного репозитория `Toropyga/pogoda_by`, включая `hacs.json`, `custom_components`, README и иконки.
2. В настройках репозитория задать описание, например `Pogoda.by weather observations for Home Assistant`, темы `home-assistant`, `hacs`, `weather`, `pogoda-by` и оставить включёнными Issues.
3. В Home Assistant 2026.11 и новее открыть **Настройки → Marketplace → Add from link**, указать URL репозитория, при необходимости подключить GitHub и установить интеграцию. Если Marketplace запросит тип, выбрать **Integration**. На старых версиях использовать пользовательский репозиторий HACS.
4. Проверить настройку станции, наличие сенсоров, иконку на поддерживаемой версии Home Assistant и последующее обновление через Marketplace / HACS. Перезапуск после первой установки через Marketplace выполнять, если он запрошен; обновление установленной интеграции требует перезапуска. Эти проверки ещё не выполнялись.

Без GitHub Releases Marketplace / HACS использует основную ветку. Для версионного распространения используйте полноценный Release с тегом `v0.1.1`, соответствующим версии `0.1.1` в manifest. Одного тега для версионного релиза недостаточно. Описание выпуска на русском и английском находится в `RELEASE_NOTES.md`.

## Пользовательский репозиторий и общий каталог

Добавление пользовательского репозитория позволяет устанавливать и обновлять интеграцию через Marketplace / HACS по её URL. Для этого не нужно подавать заявку в общий каталог.

Для появления в общем каталоге без добавления URL потребуется отдельная заявка в `hacs/default`. Перед ней нужны успешные официальные проверки HACS и hassfest, опубликованный Release, подходящая лицензия и остальные требования каталога. Лицензия в рамках этой задачи не выбиралась, заявка не подавалась.
